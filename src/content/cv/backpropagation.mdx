## The problem back-propagation solves

A network is a composition of simple functions: linear maps, then non-linearities, then linear maps again. To train it with gradient descent we need $\partial L/\partial w$ for **every** weight. Computing each derivative separately would repeat the same work millions of times. **Back-propagation** is the chain rule organised so that each intermediate derivative is computed exactly once, and the whole gradient costs about as much as one extra forward pass.

## Forward pass

For layer $l$ with weights $W^{(l)}$, bias $\mathbf b^{(l)}$ and activation $\phi$:

$$
\mathbf z^{(l)} = W^{(l)}\mathbf a^{(l-1)} + \mathbf b^{(l)}, \qquad \mathbf a^{(l)} = \phi\big(\mathbf z^{(l)}\big), \qquad \mathbf a^{(0)} = \mathbf x
$$

We store every $\mathbf z^{(l)}$ and $\mathbf a^{(l)}$, because the backward pass needs them.

## Backward pass

Define the **error signal** of a layer as $\boldsymbol\delta^{(l)} = \partial L/\partial\mathbf z^{(l)}$. For a sigmoid output unit trained with binary cross-entropy it is simply

$$
\delta^{(L)} = \hat y - y
$$

<Callout type="math" title="The recursion">

A unit's pre-activation $z_j^{(l)}$ affects the loss only through the units it feeds in the next layer, so by the chain rule

$$
\delta_j^{(l)} = \phi'\big(z_j^{(l)}\big)\sum_k W_{kj}^{(l+1)}\,\delta_k^{(l+1)} \qquad\Longleftrightarrow\qquad \boldsymbol\delta^{(l)} = \big(W^{(l+1)\top}\boldsymbol\delta^{(l+1)}\big)\odot\phi'\big(\mathbf z^{(l)}\big)
$$

And since $z_j^{(l)} = \sum_i W_{ji}^{(l)}a_i^{(l-1)} + b_j^{(l)}$,

$$
\frac{\partial L}{\partial W_{ji}^{(l)}} = \delta_j^{(l)}\,a_i^{(l-1)}, \qquad \frac{\partial L}{\partial b_j^{(l)}} = \delta_j^{(l)}
$$

Each weight's gradient is "the error at its output times the activation at its input".

## Automatic differentiation

Frameworks such as TensorFlow.js implement this bookkeeping automatically as **reverse-mode automatic differentiation** (Linnainmaa, 1970). Every operation records how to propagate a gradient backwards, and `tf.grad` replays the recording in reverse. You can try it in the Sandbox's *Tensor sandbox*.

## Summary

- The forward pass computes and stores activations, and the backward pass propagates error signals $\boldsymbol\delta$ with one matrix product per layer.
- Weight gradients are outer products of each layer's error signal and its input activations.
- Gradient checking against finite differences catches implementation bugs.
